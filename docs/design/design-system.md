# TheJobPoolConsultants visual system

The current design follows the shared midnight/navy, ivory and gold identity of the main platform. Cyan identifies technical systems and connections. The initial forest palette has been superseded.

Start with [the brand alignment audit](01-brand-alignment-audit.md), [shared design tokens](02-shared-design-tokens.md), [editorial language](03-blog-editorial-language.md), and [final visual audit](08-final-visual-audit.md).

Source: `src/styles/tokens.css`, `src/styles/global.css`, `src/styles/editorial.css`, and `src/components/Brand.astro`. Inter serves body/UI, Space Grotesk serves headings, and italic Cormorant Garamond provides gold editorial emphasis. IBM Plex Mono is limited to code and metadata.
