# Topic color system

All topics share midnight/navy, ivory and gold. Small card-edge accents identify subjects; text labels and distinct conceptual diagrams always carry the meaning.

| Topic                       | Microaccent                | Diagram language                     |
| --------------------------- | -------------------------- | ------------------------------------ |
| Machine Learning            | Semantic intelligence cyan | observations, fitted curve, residual |
| Deep Learning               | Muted violet #8974B3       | connected layers and learned outputs |
| Natural Language Processing | Slate blue #7E93BD         | tokens and vector columns            |
| Generative AI               | Semantic editorial gold    | retrieved documents, context, answer |
| Agentic AI                  | Semantic intelligence cyan | decision/action loop with feedback   |
| Computer Vision             | Muted periwinkle #8A8BCA   | image patches and region boundary    |

Colors other than semantic text colors are decorative accents, not small body text. No topic introduces a full-page accent-colored background. Evaluation uses semantic teal within diagrams; red is reserved for failures, not used as a category color. Other domains use the shared system colors.

`data-topic` selects microaccents. `ConceptArt.astro` selects actual subject structure, independent of card position; reordering articles no longer changes their illustration. The existing concept taxonomy is retained, including areas where articles are still in preparation.
